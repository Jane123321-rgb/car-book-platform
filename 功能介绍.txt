============================================================
  车书知识库管理平台 — 功能介绍与使用教程
============================================================

一、技术架构

  1. 前端
     - 语言：HTML5 + CSS3 + JavaScript (ES6+)
     - 架构：纯原生开发，零框架依赖，无构建工具
     - 设计模式：状态驱动渲染（State-Driven Rendering），
       所有 UI 由统一的 render() 函数根据状态对象重新绘制
     - 数据持久化：浏览器 localStorage，无需后端数据库

  2. 后端
     - 语言：Node.js
     - 功能：静态文件服务器 + LLM API 代理
     - 打包工具：pkg（将 Node.js 应用编译为独立 .exe）

  3. 数据存储
     - 方式：浏览器 localStorage
     - 优势：零配置、离线可用、数据跟随浏览器
     - 注意：清除浏览器缓存会丢失数据；不同浏览器数据不互通
     - 存储结构：
       {
         uploads: [],           // 车书上传列表
         knowledgeBases: [],    // 知识库列表
         idCounter: 7,          // ID 自增计数器
         apiConfig: {}          // LLM API 配置
       }

  4. AI 模型对接
     - 支持提供商：DeepSeek（默认）、Groq
     - 调用方式：通过 /api/generate 代理转发至 OpenAI 兼容接口
     - 生成内容：结构化知识库（Markdown 格式），
       包含概述、核心章节、关键知识点和使用建议


二、安装与使用

  【方式一：EXE 版（推荐，无需安装 Node.js）】
    1. 解压 车书知识库管理平台_EXE版.zip
    2. 双击 车书知识库管理平台.exe
    3. 浏览器自动打开 http://localhost:8081/
    4. 进入「生成知识库」→ 右上角「模型配置」→ 填入 API Key
       （DeepSeek 注册地址：https://platform.deepseek.com/api_keys）
    5. 开始使用

  【方式二：源码版（需安装 Node.js）】
    1. 安装 Node.js（https://nodejs.org，选 LTS 版本）
    2. 命令行进入项目目录，执行：node server.js
    3. 浏览器访问 http://localhost:8081/

  【端口说明】
    - 默认端口：8081
    - 如端口被占用，修改 server.js 第 7 行 PORT 变量
    - 关闭 exe 窗口即可停止服务

四、核心设计模式

  1. 状态驱动渲染（State-Driven Rendering）
     所有模块共用一个 state 对象，任何数据变更后调用 render()
     统一重绘 UI，确保数据一致性。render() 在每次重绘后自动调用
     saveData() 持久化到 localStorage。

  2. 事件委托（Event Delegation）
     按钮事件通过 data-act 属性统一绑定，避免为每个按钮单独注册
     事件，提升性能。

  3. 列宽拖动（Column Resize）
     通过 mousedown/mousemove/mouseup 事件实现，拖动结束后设置
     resizeJustEnded 标记，阻止后续 click 事件触发排序，解决
     拖动与排序冲突问题。

  4. 详情页模式（Detail View）
     通过 state.detailItem + state.detailType 控制，render()
     根据详情类型渲染对应详情页，返回按钮清除状态回到列表。


五、状态值定义

  车书状态：
    待提交(draft) → 已撤销(revoked) → 待生成知识库(pending_gen)
    → 待审核(pending_review) → 审核不通过(rejected) → 已上线(online)
    → 已回退(rollback)

  知识库生成状态：
    待生成(pending) → 生成中(processing) → 已生成(completed)
    → 生成失败(failed)

  知识库审核状态：
    待审核(review) → 审核通过(approved) → 审核不通过(rejected)

  生效状态：
    已生效 / 未生效


六、API 对接说明

  接口地址：POST /api/generate
  请求格式：
    {
      "provider": "deepseek",
      "apiKey": "sk-xxx",
      "model": "deepseek-chat",
      "messages": [
        { "role": "system", "content": "系统提示" },
        { "role": "user", "content": "用户提示" }
      ]
    }
  响应格式：
    { "success": true, "content": "生成的知识库内容" }

  支持的提供商：
    - DeepSeek：https://api.deepseek.com/v1/chat/completions
    - Groq：https://api.groq.com/openai/v1/chat/completions
